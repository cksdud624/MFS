■ 파일 이름 = 이름 · 설정
  첫 낱말이 이름, 뒤는 ' · ' 나 띄어쓰기로 이어 붙이는 설정.
  hero-run.psd                         컷 폴더(겹쳐 놓기)
  hero-run · 64x64 · 100ms.psd         한 판에 64×64 칸으로 나란히(시트식), 컷마다 100ms
  hero-attack1 · once.psd              한 번만 재생(마지막 컷에서 멈춤)
  설정: once/1회 · 64x64(칸 크기) · 100ms 또는 100,100,80ms(컷 길이, 모자라면 마지막 값 반복)
        부드럽게/smooth(캐릭터 · 지형은 도트(선명)가 기본) · 도트/pixel(배경을 선명하게)
        32px(1U 당 픽셀 — 배경 · 지형, 기본 64) · 바닥1500(배경의 바닥선 픽셀 줄, 기본 맨 아래) · cap12/끝12(지형 끝 조각 픽셀)

■ 캐릭터 PSD
  · 컷 = 맨 위 폴더 하나(이름 '01 · 3f' 또는 '01 · 100ms' — 번호 순, 길이). 폴더를 숨겨 둬도 읽음.
    3f = 3프레임(기준 60fps → 50ms). 기준을 바꾸려면 파일 이름에 · 24fps 처럼.
    폴더 밖 레이어는 모든 컷에 공통(그림자 등).
  · 시트식은 파일 이름에 칸 크기 — 왼쪽 위부터 오른쪽, 줄 바꿈, 빈 칸은 건너뜀.
  · 컷 안 레이어(몸체 · 얼굴 · 헤어 · 옷 · 무기 …)는 자유. 보이기 · 불투명도 · 클리핑 마스크 · 곱하기/스크린 반영.
  · 발은 캔버스 맨 아래, 오른쪽을 보게(반대면 튜닝 패널 화면 › 캐릭터 그림 › 그림이 보는 방향 = 0).

■ 배경 bg PSD — 맨 위 레이어(또는 폴더) 하나 = 층 하나, 이름에 설정
  하늘 · 고정         화면에 붙음(화면을 덮게 늘어남)
  먼 산 · 0.2         시차 0.2(작을수록 멀어 보임). 숫자 없으면 1(결투장과 같이 움직임)
  앞 풀 · 1.2 · 앞    캐릭터 앞에 그림
  간판 · 애니 · 120ms  폴더 안의 레이어(또는 폴더)가 컷 — 반복 재생
  캔버스 가로 가운데 = 결투장 가운데, 바닥선 = 결투장 바닥. 큰 그림은 자동으로 1024 조각으로 나눔.

■ 지형
  pillar(기둥): 위 Cap 픽셀 = 윗면, 나머지 = 몸통(바닥까지 아래로 반복). 기본 Cap = 높이의 1/3.
  platform(발판): 왼쪽 · 오른쪽 Cap 픽셀 = 끝, 가운데 = 반복. 기본 Cap = 폭의 1/4. 그림 윗변 = 발판 윗면.
  위치 · 크기는 튜닝 패널 결투장 › 결투장 지형 그대로 따라감.

■ 사슬(머리카락 · 옷자락 · 장신구) — stage22: 직접 그린 그림에 뼈대 심기
- ~이름 레이어 = 휘는 그림(직접 그린 뒷머리 · 천 자락). 몸 그림에는 안 들어가고, 게임에서 뼈대를 따라 휘어서 그려져요.
- @이름 레이어 = 그 그림의 뼈 마디(같은 이름). 편집기 ‘뼈대’ 도구로 뿌리 → 끝 순서로 찍어요(점 색의 초록 값 = 순서이니 손으로 고치지 마세요).
  · 마디가 없는 컷은 가까운 컷의 뼈대를, ~ 그림이 없는 컷은 가까운 컷의 그림을 써요. 폴더 밖(공통)에 두면 모든 컷에 같이.
  · 이름 뒤 (앞) = 몸 앞, 아니면 몸 뒤.
- 그린 모양이 쉬는 자세 — 가만히 있으면 원래 그림 그대로, 달리거나 맞으면 뼈가 꺾이며 그림이 휘어요(픽셀 격자 그대로, 번짐 없음).
- 흔들림(중력 · 공기 저항 · 모양 유지 · 몸 따라가기)은 chains.json — 작업실 ‘사슬’ 칸에서 바꾸면 자동 저장.
